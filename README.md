# UnDopaUI

X を「気づいたら何十分も見ていた」画面から、「見たいものを見て、閉じられる」画面に変える Chrome 拡張機能です。

終わりのないタイムライン、増えていくいいねの数、呼び戻してくる通知バッジ。X の画面には、やめどきを見失わせる仕掛けがたくさんあります。UnDopaUI はそうした仕掛けだけを取り除きます。X を使えなくするわけではありません。

## できること

- **フォロー中の投稿だけを表示**：「おすすめ」タブを隠し、自分でフォローした人の投稿だけにします
- **20 件ごとに一区切り**：一定の件数を読むとタイムラインが止まり、「今日はここまで」にするか「もう少し読む」かを自分で選べます
- **数字を隠す**：いいね・リポスト・表示回数・フォロワー数を表示しません
- **通知バッジを隠す**：メニューの通知の数字や、タブに出る「(3)」などを消します
- **通知はメンションだけ**：いいねやリポストの通知ではなく、あなた宛ての返信やメンションだけを表示します
- **「新しいポストを表示」を隠す**：次々と新着を読み込むボタンを消します
- **トレンドやおすすめユーザーを隠す**：画面右側のトレンド・おすすめユーザーや「話題を検索」を消します
- **動画の自動再生を止める**：クリックした動画だけが再生されます

どの機能も、ツールバーのアイコンから個別にオン・オフできます。

## インストール

パソコン版の Chrome で、3 分ほどで終わります。

1. **[UnDopaUI.zip をダウンロード](https://github.com/aRySt0cat/UnDopaUI/releases/latest/download/UnDopaUI.zip)**
2. ダウンロードしたファイルをダブルクリックして展開します。できた「UnDopaUI」フォルダは、「書類」フォルダなど**消さない場所に移しておいてください**（このフォルダを消すと拡張機能も使えなくなります）
3. Chrome のアドレスバーに `chrome://extensions` と入力して開きます
4. 右上の「**デベロッパー モード**」をオンにします
5. 左上に出てくる「**パッケージ化されていない拡張機能を読み込む**」を押し、手順 2 の「UnDopaUI」フォルダを選びます
6. 開いている X のタブを再読み込みすれば完了です

ツールバーのパズルのアイコンから UnDopaUI をピン留めしておくと、設定をすぐに開けます。

## 使い方

- ツールバーの UnDopaUI アイコンを押すと設定が開きます。使いたい機能にチェックを入れてください
- 右上のスイッチで、すべての機能をまとめてオフにできます
- 一区切りまでの件数は設定で変えられます
- 一区切りで「今日はここまで」を選ぶとタイムラインが閉じます。また読みたいときはページを再読み込みしてください

## 新しいバージョンにする

1. 上のリンクから新しい UnDopaUI.zip をダウンロードして展開し、前の「UnDopaUI」フォルダと入れ替えます（置く場所は前と同じにしてください）
2. `chrome://extensions` を開き、UnDopaUI の再読み込みボタン（↻）を押します

## アンインストール

`chrome://extensions` で UnDopaUI の「削除」を押し、「UnDopaUI」フォルダも削除してください。

## ご注意

- まだ試作版です。X の画面の作りが変わると、一部の機能が効かなくなることがあります
- パソコン版の Chrome 向けです。スマホの X アプリには効きません
- 設定や閲覧した内容をどこかに送信することはありません
- YouTube ショートへの対応も準備中です
